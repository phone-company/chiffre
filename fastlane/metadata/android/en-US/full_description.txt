Chiffre is a plain notes app with one twist: every note gets an expiry date when you create it. When it runs out, the app asks whether to keep or delete the note (or, if you choose so for that note, deletes it without asking), so old, finished notes do not pile up for years.

• Encrypted with your password (AES-256-GCM, key derived with PBKDF2)
• No account, no cloud, no ads, no analytics
• No internet access
• Optional: a neutral notification when a note expires or is about to be deleted automatically (no note text, can be turned off)
• Screenshots and the recent-apps preview are blocked
• Locks itself after 60 seconds in the background
• Optional: unlock with your fingerprint in addition to the password
• Encrypted backup file for restoring or moving to another device
• Light and dark theme. The interface is currently German only.

Important: the password cannot be reset. Without it the notes cannot be read. The encryption uses standard methods but has not been independently audited. Chiffre is a hobby project and the source code is open.
